YOUR MAC, ON YOUR SCHEDULE

A task to finish.
A lid to close.

Long-running agents shouldn’t need a mouse wiggle. Agent Awake gives you a clear way to keep work running—and to let ordinary sleep return when you’re finished.

With the helper approved, closed-lid protection works on battery and charger. Your display can sleep while the Mac stays awake.

01 / A LITTLE LONGER

Choose a timer.

Keep a build or a task running for 15 minutes, a couple of hours, or a custom duration. Manual sessions end when you quit the app.

One minute to seven days
02 / BETWEEN TASKS

Stay reachable.

Choose an indefinite session when you need continuous access to an existing remote terminal. End it whenever you’re ready.

Bring your own SSH or Tailscale
03 / FOLLOW THE WORK

Use automatic mode.

Optional CLI hooks track observed Claude Code and Codex work. After the last observed task finishes, a short grace period lets sleep return.

Full instructions on GitHub ↗
What you’ll need

macOS 14 or later, an Apple Silicon or Intel Mac, and administrator approval for the closed-lid helper.

The universal build includes both architectures. Physical testing has been on Apple Silicon; Intel and older macOS versions remain unverified.

  1. 1

    Download. Unzip. Move to Applications.

    Open the ZIP in Finder, then drag Agent Awake.app into Applications. Put it there before enabling the helper, and keep it in that location.

  2. 2

    Open the preview on macOS.

    Double-click the app. If macOS blocks this unnotarized preview, open System Settings → Privacy & Security → Open Anyway, if offered. Authenticate and confirm Open only if you trust this GitHub download.

    Use Apple’s opening instructions. If the app is reported as damaged or harmful, re-download and report the alert; don’t bypass it.

  3. 3

    Look up, in your menu bar.

    Click the sun or moon icon, then the gear to open Settings. Agent Awake is a menu-bar app: there’s no Dock icon or main window waiting to open.

  4. 4

    Approve the closed-lid helper.

    In Setup, click Enable helper. Approve it under System Settings → General → Login Items & Extensions → Allow in the Background. macOS may ask for your administrator password. On macOS 14, the pane is called Login Items.

    Without this approval, the app can prevent ordinary idle sleep with the lid open; closed-lid protection is unavailable.

  5. 5

    Run the two-minute check.

    Choose Start two-minute check in Setup. Confirm the menu says Sleep prevented and lid protected. Close the lid, check an existing remote terminal from another device, and let the timer expire. Repeat on battery and charger.

    Confirm that the display turns off and normal lid sleep returns afterward. Connected external displays also receive the display-sleep request.

THE SMALL PRINT, IN PLAIN ENGLISH

Good to know.

Does it keep the screen on?

Agent Awake prevents system sleep during an active session. It does not request a display-sleep prevention assertion. With the helper approved, closing the lid requests sleep for connected displays, including external displays.

What does “Allow sleep now” do?

It ends manual sessions and pauses automatic mode until you select Resume. It allows the normal macOS sleep policy; it does not force immediate sleep with an open lid. Ending a manual session alone can still leave automatic protection active.

What if the app crashes or I quit?

Manual sessions end when the app quits. The ordinary idle-sleep assertion is released on exit. The helper releases its owned override on disconnection or lease expiry; its lease expires after 12 seconds without renewal. Crash recovery depends on macOS being able to restart the helper. See the verification report for tested behavior and remaining hardware checks.

Will it drain my battery?

A Mac that stays awake continues to use energy. Protection works on battery and charger. You can enable a battery cutoff in Preferences; it’s off by default, and when enabled it overrides manual and automatic sessions on battery.

Does it read my prompts or send data anywhere?

The app makes no network requests and has no accounts or analytics. Agent hooks receive CLI event payloads but discard prompts, tool contents, working directories, and transcript paths. Only activity metadata is saved locally. Backups of existing hook configuration remain private beside those files.

How do I update or remove it?

Choose Settings → Diagnostics → Remove integrations first. Wait for successful sleep restoration, then quit. For an update, replace the app in the same Applications location and set up the helper and hooks again. To uninstall, move the app to Trash after removing integrations. Unrelated hooks and configuration backups are preserved.

Can I use it with other keep-awake tools?

The helper uses the same global sleep-disable setting as pmset. An existing external setting is preserved, and an observed external change to allow sleep is respected. That global switch cannot provide independent ownership for multiple apps. Agent Awake does not change your shell aliases.

The helper isn’t ready, or activity is unknown.

Check Diagnostics and macOS’s background-item approval. Unknown activity usually means the CLI hasn’t loaded the hooks yet: install them, trust them in Codex, and restart the session. For full troubleshooting and issue-report details, read the README.
